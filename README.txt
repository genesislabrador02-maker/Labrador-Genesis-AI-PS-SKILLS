GENESIS LABRADOR PORTFOLIO — CLEAN IMAGE VERSION

HOW TO REPLACE YOUR PHOTOS

1. Open the images folder.
2. Replace the existing hero.jpg with your own first-page photo.
   Keep the filename: hero.jpg
3. Replace the existing profile.jpg with your own second-page photo.
   Keep the filename: profile.jpg
4. Refresh index.html in your browser.

IMAGE STYLE
- No border
- No frame
- No box background
- No overlay on the first/second page image slots
- First page image is set to 280 x 380 on desktop.
- Second page image is a larger free-floating image area.
- PNG with transparent background is recommended for the second page if you want the portrait to appear completely free-floating like the sample.

WORKS
- Work thumbnails remain grayscale for the portfolio aesthetic.
- Clicking a work opens the original full-color image.

IMAGE NOTE: hero.png is a transparent cutout. Replace it with your own transparent PNG if you want the same floating/no-box effect.
